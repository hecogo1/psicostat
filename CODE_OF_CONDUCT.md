# Código de conducta / Code of Conduct

Este proyecto adopta el [Contributor Covenant, versión 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Nuestro compromiso / Our pledge

Queremos que participar en PsicoStat sea una experiencia libre de acoso para todas las personas, independientemente de edad, cuerpo, discapacidad, etnia, identidad y expresión de género, nivel de experiencia, educación, nivel socioeconómico, nacionalidad, apariencia, raza, religión u orientación sexual.

We pledge to make participation in our community a harassment-free experience for everyone.

## Comportamiento esperado / Expected behaviour

- Ser amable y respetuoso/a, también con quien está aprendiendo estadística / Be kind, especially to learners.
- Aceptar críticas constructivas y centrarse en lo mejor para la comunidad / Accept constructive feedback.
- No se tolera el acoso, los insultos ni la publicación de datos privados / Harassment, insults and doxxing are not tolerated.

## Aplicación / Enforcement

Informa de comportamientos inaceptables a la persona mantenedora del proyecto (ver perfil de GitHub del mantenedor). Todas las quejas se revisarán con confidencialidad.
Report unacceptable behaviour to the project maintainer (see the maintainer's GitHub profile). All complaints will be reviewed confidentially.
